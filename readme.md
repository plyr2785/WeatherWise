# 🌦️ WeatherWise

WeatherWise is a modern weather forecasting web application that provides real-time weather information for any city around the world. Built with a clean, responsive interface, it delivers accurate weather conditions, temperature, humidity, wind speed, and more using a weather API.

![WeatherWise Banner](https://via.placeholder.com/1200x400?text=WeatherWise)

## ✨ Features

- 🌍 Search weather by city name
- 🌡️ Real-time temperature display
- ☁️ Weather conditions with icons
- 💧 Humidity information
- 💨 Wind speed
- 🌅 Sunrise & Sunset timings
- 📱 Fully responsive design
- ⚡ Fast and lightweight interface

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- OpenWeather API *(or your weather API)*
- Fetch API

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/vamshi-thota/WeatherWise.git
```

### 2. Navigate to the project folder

```bash
cd WeatherWise
```

### 3. Add your API Key

Open `script.js` and replace:

```javascript
const API_KEY = "YOUR_API_KEY";
```

with your own Weather API key.

### 4. Run the project

Simply open `index.html` in your browser.

Or use VS Code Live Server for a better development experience.
